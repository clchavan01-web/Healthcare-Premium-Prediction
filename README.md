# Healthcare Premium Prediction

A machine learning application that predicts healthcare insurance premium costs based on user details using Linear Regression.

## Project Overview
- **Learning Type**: Supervised Learning
- **Task**: Regression
- **Algorithm**: Linear Regression
- **Goal**: Predict continuous numerical values for healthcare insurance premiums.

## Project Structure
- `app.py`: Web application interface (Streamlit / Flask / FastAPI)
- `main.py`: Entry point script
- `train_model.py`: Model training script
- `predict_test.py`: Model testing / inference script
- `healthcare_model.pkl`: Saved trained model
